# medical-solution-alerts

Justificación: 
La aplicación móvil tiene como objetivo optimizar el proceso y control de soluciones aplicadas a los pacientes de un hospital público. El sistema se desarrolla en el lenguaje de programación Java, ya que es un lenguaje orientado a objetos robustos y utilizado para el desarrollo de aplicaciones. Actualmente se tiene el código en el IDE IntelliJ IDEA por la facilidad de gestionar proyectos y sus herramientas integradas para realizar una depuración. El sistema a desarrollar es un entregable de una aplicación móvil, es por ello que el código actual se trabaja continuamente en migrar hacia el IDE Android Studio, se busca entregar un sistema profesional y aprovechar la compatibilidad con Java en el entorno Android.

Descripción del proyecto:
Una aplicación móvil dirigido al personal de salud que permite obtener un impacto automatizado a una actividad manual y reducir gastos en la obtención de tiras horarias; los resultados de esta aplicación ofrecen:
•	Alerta de termino de solución aplicada al paciente.
•	Resultado inmediato de conteo de gotas por minuto de solución aplicada a un paciente con opción de normogotero o microgotero.
•	Historial médico del paciente.
•	Formato de tira horaria de la solución.
El lenguaje de programación para este proyecto es Java, un lenguaje orientado a objetos y actualmente se tiene la estructura de clases, atributos y métodos en el IDE IntelliJ DEA pero se busca migrarlo hacia el IDE Android Studio ofreciendo al usuario una aplicación intuitiva.

Correr código: Se usa lenguaje de programación Java y el IDE IntelliJ IDEA.
